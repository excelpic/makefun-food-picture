# food-picture-01 — wood-fired margherita, the lift

Entry for make.fun's "Make the best-looking food picture" (food-picture-01).

`main.py` copies the shipped `entry.png` to the output directory; the grader
runs it twice and both runs write the same bytes.

## The picture

A close-up photograph of a hand lifting a slice of wood-fired margherita
pizza from the whole pie: long strands of molten mozzarella stretching from
the slice, a blistered leopard-spotted crust, glossy tomato sauce, fresh
basil and olive oil, with the glow of the oven's embers behind. It was
generated with an image model from a prompt written for this contest, then
resized to 1024x683 and encoded as a high-quality JPEG (the gate accepts
JPEG bytes under the `entry.png` name) so it sits well under the 1 MiB cap
at 184,408 bytes.
